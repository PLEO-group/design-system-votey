# Konflikt szablonu Angulara przy dodawaniu selektorów testowych

Gdy jedna strona konfliktu zmienia wyłącznie selektory testowe, a druga sposób odtwarzania kontrolki, zachowaj strukturę i wiązania poprawki, w tym śledzenie instancji oraz argumenty zdarzeń. Przenieś `data-cy` na element pełniący tę samą funkcję w nowej strukturze. Porównaj wynik z poprawioną wersją po pominięciu atrybutów testowych i różnic formatowania, które nie zmieniają znaczenia szablonu. Osobno sprawdź kompletność i umiejscowienie dotychczasowych selektorów.
